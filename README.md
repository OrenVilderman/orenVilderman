## Engineering Principles

- Keep AI responsibilities bounded and explicit.
- Validate external and user-controlled input at system boundaries.
- Design for realistic failure modes, not only happy paths.
- Prefer the smallest architecture that solves the actual requirement.
- Add infrastructure when a concrete requirement justifies it.
- Measure before making performance claims.
- Treat tests and verification as part of the engineering design.
